Was ist C?

C ist eine Programmiersprache, mit der man dem Computer genaue Anweisungen gibt. Viele wichtige Dinge wurden (oder werden) mit C gebaut, zum Beispiel Teile von Betriebssystemen oder Software für Geräte.

Denk dir Programmieren wie eine Wegbeschreibung: Du sagst jemandem "Geh 10 Meter rechts und danach 50 Meter Links und dann bist du am Ziel" Wenn du ihm die falschen Angaben gibst, verläuft er sich und kommt nicht zum Ziel.

Diese Seite erklärt nur die Grundlagen: Ein/Ausgabe, Variablen, If/Else, Schleifen, Arrays. Alles mit einfachen Beispielen.

Kurzfakten

Startpunkt: main Text ausgeben: printf Eingabe lesen: scanf Bedingung: if / else Wiederholen: for Listen: Arrays

Grundideen

Wenn du nur diese Ideen verstehst, bist du schon weit:

  • Ein-/Ausgabe: Der Computer kann Text zeigen (printf) und Eingaben lesen (scanf).
  • Variablen: Ein "Behälter", in der ein Wert gespeichert wird (z. B. eine Zahl oder ein Buchstabe).
  • Datentypen: Welche Art von Wert in der Box liegt (z. B. int, float, char).
  • Kontrollstrukturen: Entscheidungen treffen: „Wenn das stimmt, dann … sonst …“ (if/else).
  • Schleifen: Wiederholen: „Mach das 10-mal“ (for).
  • Arrays: Mehrere Werte unter einem Namen speichern (wie eine Liste).
Mini-Spickzettel: So liest man C-Code
  • ; beendet eine Anweisung (wie ein Punkt am Satzende).
  • { } fasst mehrere Anweisungen zu einem Block zusammen.
  • "Text" ist ein String (Text in Anführungszeichen).
  • // Ist ein Kommentar. Wird vom Computer ignoriert. Ein Kommentar ist nur für den Programmierer oder leser.

1) Ein- und Ausgabe

printf zeigt Text auf dem Bildschirm.
scanf liest eine Eingabe ein (z. B. was jemand tippt).

printf = raus, scanf = rein

Beispiel: „Gib deinen Namen ein“ das Programm gibt ihn wieder aus.

Dieses Beispiel ist oft beim Registrieren zu beobachten. Man macht und ein neues Konto und man wird mit dem Namen begrüßt, den man eingegeben hat.

#include <stdio.h>

int main(void) {
    char name[50];  // man erstell eine Variable mit dem Datentyp char.
                    // die Variable heißt "name" und kann 

    printf("Gib deinen Namen ein: ");
    scanf("%s", name);   // liest das Wort und schreibt es oben in der Variable

    printf("Hallo, %s!\n", name);     // Text in Anführungszeichen wird dem User gezeigt
    return 0;
} // Code von Mustafa

Hinweis: Dieses Beispiel liest nur ein Wort. Mehrere Wörter (z. B. Vor- und Nachname) geht auch, ist aber etwas extra.

Was bedeuten die Zeichen?

  • %s steht für „Text“ (String).
  • \n bedeutet „neue Zeile“.
  • char name[50] = Platz für bis zu 49 Zeichen (plus Endezeichen).
  • return 0; bedeutet, dass diese Funktion erfolgreich bis zum Ende ausgeführt wurde. return 1; oder andere ziffern bedeutet, die Funktion wurde nicht erfolgreich ausgeführt.
Typischer Fehler

Wenn man bei scanf falsche Platzhalter benutzt (z. B. %d statt %s), bricht das Programm ab.

2) Variablen und Datentypen

Eine Variable ist eine Box mit einem Namen, in der ein Wert gespeichert wird.

  • int = ganze Zahl (z. B. 5, -2)
  • float = Zahl mit Komma (z. B. 3.14)
  • char = einzelnes Zeichen (z. B. 'A')

Beispiel: Zwei Zahlen addieren.

#include <stdio.h>

int main(void) {
    int a, b;     2 Variablen des Datentyps intger mit dem Namen a und b.

    printf("Zahl 1: ");
    scanf("%d", &a);

    printf("Zahl 2: ");
    scanf("%d", &b);

    printf("Summe: %d\n", a + b);
    return 0;
} // Code von Mustafa

Warum steht da &a?

Für Anfänger reicht: scanf braucht bei Zahlen das &, damit es den Wert richtig „eintragen“ kann.

Erklärung

Bei scanf für Zahlen fast immer: &variable.

& zeigt auf die Adresse der Variable im Speicher

3) Kontrollstrukturen: if und else

if bedeutet: „Wenn das stimmt, dann …“
else bedeutet: „Sonst …“

Beispiel: Prüfen, ob eine Zahl positiv oder negativ ist.

#include <stdio.h>

int main(void) {
    int x;    Eine Variable des Datentyps int mti dem Namen x.
    printf("Gib eine Zahl ein: ");
    scanf("%d", &x);

    if (x > 0) {
        printf("Die Zahl ist positiv.\n");
    } 
    else if (x == 0) {
        printf("Die Zahl ist 0.\n");
    }
    else {
        printf("Die Zahl ist negativ.\n");
    }
     return 0;
} // Code von Mustafa

Wichtig

  • > bedeutet „größer als“
  • >= bedeutet „größer oder gleich“
  • == bedeutet „gleich“ (nicht =!)

4) Schleifen: for

Eine for-Schleife wiederholt etwas, z. B. „drucke Zahlen von 1 bis 10“.

Beispiel: Zahlen von 1 bis 10 ausgeben.

#include <stdio.h>

int main(void) {
    int i;
    for (i = 1; i <= 10; i++) {
        printf("%d\n", i);
    }
    return 0;
} // Code von Mustafa

Wie liest man das?

  1. i = 1 → starte bei 1
  2. i <= 10 → solange i ≤ 10
  3. i++ → i wird jedes Mal um 1 größer

5) Arrays

Ein Array ist wie eine kleine Liste: mehrere Werte unter einem Namen.

Beispiel: Drei Noten speichern und den Durchschnitt berechnen.

#include <stdio.h>

int main(void) {
    float punkte[3];

    printf("Note 1: ");
    scanf("%f", &punkte[0]);

    printf("Note 2: ");
    scanf("%f", &punkte[1]);

    printf("Note 3: ");
    scanf("%f", &punkte[2]);

    float durchschnitt = (punkte[0] + punkte[1] + punkte[2]) / 3;
    printf("Durchschnitt: %.2f\n", durchschnitt);

    return 0;
} // Code von Mustafa

Wichtige Idee

Bei Arrays beginnt das Zählen bei 0:

  • noten[0] = erstes Element
  • noten[1] = zweites Element
  • noten[2] = drittes Element
